# 青森県 市町村データ100 かんたんマップ＆レポート

青森県の公式統計「令和8年 青森県統計年鑑 市町村データ100（全105項目）」を手軽に可視化し、**A4用紙1枚の分析レポートとして印刷・PDF保存できる**軽量Webツールです。

複雑な設定やデータ編集をすべて省略し、**「指標を選ぶ」「地図を見る」「A4レポート印刷」**の3ステップだけで誰でも直感的に操作できるように設計されています。

---

## 主な特徴

1. **令和2年国勢調査人口による「人口1,000人あたり」変換機能（率化）**
   * 元のツール（`choropleth-tool`）で好評だった人口規模平準化機能をシンプルに移植。
   * サイドバーの「**実測値**」と「**人口1,000人あたり**」の2択ボタンをワンタップするだけで、自治体の人口規模（青森市27万人〜西目屋村1,200人）の格差を補正した1,000人対比率に即座に切り替わります。
   * 地図の塗り分け、ツールチップ、全県統計サマリー、ランキング、A4レポート印刷のすべてに連動します。

2. **人間の感覚に即した自然な「キリの良い数値」階級区分（Smart Snapped Breaks）**
   * 機械的な分位数計算による `6,432.4 〜 12,855.2` のような端数を排除。
   * 自治体数が各階級にバランスよく分散する利点を保ちつつ、各階級の境界値を桁数に応じた**人間が認知しやすい丸い数値（例: 5,000 / 10,000 / 30,000 や 10% / 15% / 20% 等）**に自動スナップ。
   * 凡例表示も `〜 5,000`、`5,000 〜 10,000`、`30,000 〜` のように端数のない極めて自然な区分表記となり、行政報告書や新聞のような説得力あるマップとレポートが得られます。

3. **歪みのない正確な地図投影（縦横比の完全維持）**
   * 画面上のLeafletマップ、および印刷プレビュー時のA4ベクターSVGマップの両方で、アスペクト比を100%正確なメルカトル正角投影（縦横比 1 : 1.03）に補正。
   * 印刷プレビュー時にも地図が横や縦に引き伸ばされることなく、美しい形状で中央にピッタリ収まります。

4. **画面領域いっぱいに固定最大拡大された地図表示**
   * マウス操作による地図のドラッグ移動やホイールズームを無効化し、地図が不用意に動いたりずれたりしない固定ダッシュボード設計。
   * Leafletの整数ズーム制約（zoomSnap）を解除し、パディングゼロで画面コンテナの幅・高さの限界までピッタリ最大サイズで拡大表示。
   * ステータスバーを地図の上に浮かぶフローティングバッジ化することで、縦の無駄なスペースを完全排除。
   * サイドバー開閉ボタン（`☰`）でサイドバーを折りたためば、横幅100%の超大画面マップにも瞬時に切り替わります。

5. **オンデマンドの「統計サマリー＆順位」パネル**
   * 通常時は地図を邪魔しないよう、統計サマリーパネルは非表示です。
   * 右上の「📊 統計サマリー」ボタンをクリックした時だけ、全県平均・中央値・最大/最小自治体、上位・下位自治体ランキングがスムーズに表示されます。

6. **完全自己完結・Web公開に最適（単一HTML対応）**
   * サーバーサイドのバックエンド処理は一切不要。
   * GitHub Pagesなどの静的ホスティングで即日公開可能。
   * 完全スタンドアロン版（`index_standalone.html`）は、ローカルPCでダブルクリックするだけで通信不要・オフラインでも動作します。

7. **元のツールと完全一致の「A4縦置き（Portrait）」高機能分析レポート印刷**
   * 「A4レポート印刷」ボタンを押すだけで、元のツール（`choropleth-tool`）と全く同一仕様のA4縦置きレポートが開きます。
   * **上段（最大化ベクター地図 & 階級凡例）**: 用紙幅いっぱいに広がる等角メルカトル投影（縦横比 1 : 1.03）の高精細ベクターマップ。
   * **中段（基本統計サマリー ＆ データ分布図）**:
     - 左側: 対象数、合計、平均値、中央値、最大自治体、最小自治体、標準偏差、四分位範囲のコンパクト2列×4行テーブル（人口1,000人対の注記付き）。
     - 右側: **7階級度数ヒストグラム**、**ガウス核によるカーネル密度推定（KDE）曲線**、平均値（黒破線）・中央値（濃灰破線）のリファレンスライン。
   * **下段（40市町村 棒グラフ）**:
     - 全40市町村を降順（多い順）に並べた垂直棒グラフ。
     - 各バーは地図と同じ階級カラーで塗り分けられ、白抜けを防ぐ明瞭な縁取り付き。
     - 赤破線の全県平均値基準線（`平均: ○○`）および90度回転の自治体名ラベルを配置。
   * ブラウザ標準印刷（PDF保存）のほか、**「PNG画像保存」**や**「クリップボードにコピー（Word/PowerPoint貼付用）」**にも対応。

## 収録データ（全105指標）

青森県企画政策部 統計分析課「令和8年 青森県統計年鑑 市町村データ100」より収録：

* **人口・世帯・面積（11指標）**: 総面積、人口、人口密度、世帯数、労働力人口、出生数、出生率、婚姻件数・率、離婚件数・率
* **産業・就業・商業（20指標）**: 就業者数（産業別）、事業所数、従業者数、製造業（事業所数・従業者数・出荷額・粗付加価値額）、商業（卸売・小売・飲食料品）
* **農林水産業（12指標）**: 販売農家数、法人化農家数、耕地面積（田・畑）、水稲収穫量、林野面積、漁業就業者数、海面漁獲数量・金額
* **経済・財政・所得（24指標）**: 市町村内総生産（各産業別・小計）、1人当たり市町村民所得、歳入、地方税、歳出、財政力指数、積立金現在高
* **医療・保健・福祉（22指標）**: 病院数、病床数、一般診療所数、医師数・歯科医師数・薬剤師数（実数および人口10万人対）、死亡数・死因別内訳、老人福祉施設、保育所、認定こども園、生活保護率
* **教育・生活・環境・安全（16指標）**: 大学等進学率、就職者の割合、図書館・公民館蔵書数、自動車保有台数、道路実延長、都市公園面積、ごみリサイクル率、水道普及率、交通事故、火災出火件数、刑法犯認知・検挙件数

## 画面構成と使い方

### 1. 指標の選択
画面左のサイドバーから、興味のある分野を選び、リストまたは検索バーから指標をクリックします（または上部のクイックピックタグをクリック）。

### 2. 人口補正（率化）の切り替え
「2. 人口補正（率化）」で、実測値で見るか、人口規模格差を平準化した「人口1,000人あたり」で見るかを選択します。

### 3. 配色の選択
「3. 塗り分けカラー」からお好みのテーマカラー（ブルー、グリーン、オレンジ、パープル）を選択します。

### 4. 地図の確認と最大化
中央の地図で各市町村の色分けを確認します。
* 市町村にマウスを当てると、詳細な数値と全県内での順位が表示されます。
* 画面左上の `☰` ボタンを押すとサイドバーが折りたたまれ、画面全体に地図が最大拡大されます。
* 右上の「**📊 統計サマリー**」ボタンを押すと、全県平均値や上位・下位自治体のサマリーパネルが表示されます。

### 5. レポートの印刷・保存
画面右上の「**A4レポート印刷**」ボタンを押します。
プレビューモーダルが開くので：
* **印刷 / PDFとして保存**: ブラウザの印刷ダイアログからA4（縦向き）で印刷またはPDF保存します（用紙設定が自動的にA4 Portraitに適用されます）。
* **画像保存 (PNG)**: 高解像度の画像ファイルとしてダウンロードします。
* **画像をコピー**: クリップボードにコピーし、WordやPowerPointに直接貼り付け（Ctrl+V）します。

## GitHub Pages での公開手順

1. 本リポジトリを GitHub にプッシュします。
2. GitHub のリポジトリページで **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Branch** で `main`（または `master`）の `/ (root)` を選択し、**Save** をクリックします。
4. 数十秒後に公開用URL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行され、誰でもブラウザからアクセス可能になります。

## 起動方法

### 1. Web公開（GitHub Pages）
GitHubリポジトリの **Settings** > **Pages** で `main` ブランチの `/ (root)` を指定して公開すれば、インストール不要ですぐにWeb利用できます。

### 2. ローカル実行
* **Windows**: `kidou.bat` をダブルクリックするだけでブラウザが起動します。
* **Linux / macOS**: `./start_server.sh` をターミナルで実行するとローカルサーバーが立ち上がりブラウザが開きます。
* **オフライン・完全単体利用**: `index_standalone.html` を任意のブラウザでダブルクリックするだけで動作します。
